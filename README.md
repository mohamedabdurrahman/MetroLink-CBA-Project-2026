# MetroLink Cost-Benefit Analysis (Ireland)

## Project Overview
Independent Cost-Benefit Analysis of Dublin's proposed MetroLink rail project, prepared in the style of infrastructure advisory practice.

**Key Results (€9.5bn Cost Base):**

| Metric | Value |
|--------|-------|
| Capital Cost | €9.5 billion |
| NPV (Core Model) | -€2.6 billion |
| BCR (Core Model) | 0.70 |
| Official PBC BCR | 1.4 |
| IRR | 2% |

## Methodology Highlights
- 60-year discounted cash flow model
- 4% real discount rate (Irish Government Infrastructure Guidelines)
- S-curve capital spend (5-15-30-30-15-5)
- Deadweight adjustment (25%)
- Residual value (30% of capital)
- Sensitivity analysis (5 scenarios)
- Tornado diagram (BCR drivers)
- Risk register (5 key risks)

## Data Sources
- MetroLink Preliminary Business Case (2022) – €9.5bn cost, €13.7bn benefits, BCR 1.4
- Irish Government Infrastructure Guidelines (2023) – 4% discount rate
- Department of Finance (April 2026) – 2% growth rate
